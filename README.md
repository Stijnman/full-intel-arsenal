# full-intel-arsenal

Merged **defensive** intelligence skill combining:

- Competitive GitHub analysis  
- Public OSINT hygiene  
- YouTube channel metrics tools  
- Vulnerability **awareness** from public advisories  

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## Install (Grok / agent skills)

```bash
git clone https://github.com/Stijnman/full-intel-arsenal.git
mkdir -p ~/.grok/skills/full-intel-arsenal
cp SKILL.md ~/.grok/skills/full-intel-arsenal/
```

## What this is

A single `SKILL.md` agents can load to run structured research workflows. It is **read-only and defensive** — competitive analysis and CVE awareness, not offensive tooling.

## What this is not

- Not a 0-day exploit kit  
- Not a doxxing or credential-theft toolkit  
- Not authorized for private-system access without permission
