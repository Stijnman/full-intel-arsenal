# Example: Competitive GitHub Analysis

**Input:**
```
Analyze this repository and give me a prioritized implementation roadmap with GitHub CLI commands: https://github.com/example-org/cool-project
```

**What the skill does:**
- Deeply inspects the target repo (README, code, issues, activity, tech stack)
- Identifies 6–10 relevant competitors (GitHub + SaaS + websites)
- Builds a feature comparison matrix
- Produces Gap Analysis + P0-P3 prioritized roadmap
- Gives ready-to-run `gh` commands for the top recommendations

**Expected Output Style:**
- Executive Summary (biggest gaps + highest ROI moves)
- Clean competitors table
- Feature matrix
- Prioritized roadmap table
- Detailed implementation suggestions with files, code snippets, and `gh checkout`, `gh commit`, `gh pr create` commands
- Risks & next steps

**Why this is valuable:**
Turns hours of manual competitive research + planning into a structured, actionable artifact in minutes.
