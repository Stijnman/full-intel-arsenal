# Example: OSINT Investigation

**Input:**
```
Perform a full OSINT investigation on john.doe@targetcompany.com. Include confidence levels and sources.
```

**What the skill does:**
- Uses public tools and methods across domains, social, email, and company footprint
- Cross-references findings
- Assigns High/Med/Low confidence to every claim
- Produces structured output with full attribution

**Expected Output Style:**
- Executive Summary with key findings
- Target Profile table (with confidence + source for each attribute)
- Digital Footprint section
- Timeline (if relevant)
- Connections & Risk Assessment
- Tools used + Gaps/Uncertainties

**Why this is valuable:**
Professional-grade, defensible OSINT output instead of scattered tool results.
